# Native review submission and browsing — 2026-10-16

## Delivered

- Replaced the free-text/one-lecturer submission form with course and term selection from the catalogue and multiple instructor/session evaluations. Course → Evaluate → Preview uses spring transitions, Material theme colors, wrapping controls and keyboard-safe scrolling.
- Course workload, difficulty and usefulness are explicitly chosen. Ratings support 0–5 in half steps and N/A; grade supports the web `-1` prefer-not-to-disclose value. Each instructor has separate teaching/grading ratings, comments, assessment requirements and service-learning details. Known service-learning types are populated from teaching records.
- The write boundary verifies the signed-in account, actual teaching records, maximum seven reviews per term, maximum two per course, and the failed-course retry rule. Eligibility errors prevent publishing. The payload uses existing web fields; no backend/schema change.
- Account-scoped SharedPreferences drafts retain all answers for seven days. Restore happens once per account; success/discard clears the draft. Course/term changes warn before clearing answers, and selecting the current value is a no-op. Failed submission keeps the draft; duplicate taps are guarded. Account switches replace private state and late results cannot navigate another account.
- Latest, course, instructor and personal review browsing now uses complete paginated source data with 30-row display batches. The instructor feed matches every instructor/session, including older reviews beyond the previous 200-row cutoff.
- Shared searchable multi-select filters cover course, instructor, grade, term, review language, session type, assessment and service learning. Sorting covers date, workload, difficulty, usefulness, teaching, grading, grade and votes; N/A sorts last. Full-review sheets show all instructor comments and requirements.
- Public vote counts are joined from the existing vote table with pagination. Account changes refresh selected-vote state. The Discover preview stays at five reviews and reuses the existing course catalogue cache for titles.
- Legacy imported JSON with unescaped control characters retains the web repair behavior; malformed details never discard the course review itself. The public source scan contained 1323 reviews, 42 with multiple evaluations, and four JSON strings rejected by strict parsing.
